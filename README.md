# Locket và YouTube — GitHub Pages

Repo: https://github.com/vd-huy/locket-youtobe-config-shadown-rocket

Gói này chứa config Shadowrocket và ba script Locket. Tải toàn bộ nội dung gói lên thư mục gốc nhánh `main`, giữ thư mục `scripts` và file `.nojekyll`.

Trong repo, mở Settings → Pages → Build and deployment → Source: Deploy from a branch. Chọn `main` và `/(root)`, rồi Save. Chờ Pages triển khai.

Kiểm tra script: https://vd-huy.github.io/locket-youtobe-config-shadown-rocket/scripts/locket-config.js

Import config vào Shadowrocket: https://vd-huy.github.io/locket-youtobe-config-shadown-rocket/Locket-YouTube.conf

Mỗi khi sửa script, cập nhật file trên GitHub, chờ Pages triển khai và cập nhật script trong Shadowrocket. YouTube vẫn dùng script jsDelivr đã ghim trong config. Script chưa được kiểm thử trên iPhone; tùy chọn riêng tư không chứng minh bảo vệ phía máy chủ. Nội dung Pages công khai: không tải token hoặc dữ liệu cá nhân lên.
